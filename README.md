# Ведомость отделки — надстройка для Archicad 27

Считает ведомость отделки помещений по зонам **HimeraZone** (объект, в имени которого есть «HimeraZone»: HimeraZone22, АСП_HimeraZone) (форма как на листе 63 тома АР):
потолки и стены по материалу — монолит ж/б, кладка/керамзитобетон, ГКЛ.

## Как пользоваться

1. «Параметры → Ведомость отделки → Ведомость отделки…».
2. В окне: номер секции (параметр зоны «Секция»), этажи (`1`, `2-14`, `1; 3; 5-7`), толщина потолка и толщина пола
   по первой цифре кода категории зоны (1 квартиры, 2 МОП, 3 подвал, 4 техпомещения, 5 встроенные).
   Толщина пола зоны: перекрытие в слое «Полы» в зоне → «Толщина пола» в параметрах зоны → значение по категории.
3. «Рассчитать» — таблица строится на рабочем листе **«Ведомость отделки - секция N»** (при повторном расчёте
   линии и тексты этого листа удаляются и рисуются заново — своё на него не добавляйте).
   Галочка «Также сохранить в Excel» — файл `Ведомость отделки - секция N - эт. X.xlsx` в «Документах»
   с проверочным листом «Расчёт» (каждая стена каждой зоны: длина, высота, проёмы, площадь).

4. Этажи в окне — номер из названия этажа («Этаж 1» → 1), как в навигаторе; если этажа с таким числом в названии нет —
   индекс этажа. Секция — из свойства «Секция №» (если в проекте есть), иначе параметр зоны «Секция».
5. Кнопка «Рассчитать + проверка зон» (или меню «Ведомость + таблица проверки зон» — без окна, с последними настройками)
   рисует справа от ведомости таблицу проверки: этаж, № зоны, имя, категория, код, площадь, подкатегория и строка ведомости
   для каждой зоны, площадь потолка, длина стен по столбцам (монолит, КБ, ГКЛ), высота отделки (и наименьшая, если есть элементы ниже зоны), проёмы и площадь стен
   по столбцам (монолит, кладка/КБ, ГКЛ), примечания (что взято по плану, какие стены
   заканчиваются ниже зоны — проверить высоту, стены без столбца); внизу — итоги по подкатегориям (= суммы подраздела ведомости).
   Выбор зоны на плане: выделите на рабочем листе текст строки таблицы проверки (имя, номер — любой текст строки; можно несколько строк)
   и запустите меню «Показать на плане зоны выделенных строк проверки» — откроется план этажа, зоны выделятся и покажутся крупно.
6. Зоны на скрытых слоях пропускаются (галочка «Пропускать зоны на скрытых слоях»). В отчёте после расчёта —
   сколько зон взято по этажам, слоям и категориям, какие пропущены (скрытые слои, другие секции, другие объекты зон),
   сколько линий и текстов нарисовано и в каком слое.

## Паспорта квартир и ТЭП

Квартира — зоны помещений квартир (категории 1xxx) с одинаковым параметром зоны **«Квартира»** (asAddOn_stApartmentCode)
на одном этаже одной секции. Площадь помещения — как в штампе зоны (asAddOn_CalcArea; если пусто — расчётная Archicad),
округляется до 0,1 и складывается. Балконы и террасы — коэф. 0,3, лоджии — 0,5.

7. «Паспорта квартир на планах этажей» — на всех этажах для каждой квартиры объект **Паспорт_АСП**
   (`gdl/Паспорт_АСП.xml`, сборка `Собрать Паспорт_АСП.bat`, затем добавить в библиотеку проекта):
   тип (1К, 2К, 3К, С — студия), жилая площадь, площадь квартиры, общая (без коэф.), приведённая (с коэф.).
   Паспорт ставится у самой большой жилой комнаты квартиры (сначала продольный фасад), в ближайшее свободное место (не на зоны любых секций, стены, колонны, другие паспорта),
   сначала со стороны, ближайшей к краю этажа; паспорта, которые не двигали вручную, при повторном запуске переставляются,
   передвинутые — только обновляются (ключ «секция|квартира», тот же этаж); паспорта исчезнувших квартир удаляются.
   Встроенные помещения (5xxx, кроме 5020) с номером в параметре «Квартира» (1005…) — паспорт «АП»: номер,
   площадь (сумма зон помещения, «84,2 м²»), высота самой большой зоны («h=3,97м»).
8. «ТЭП по дому (таблица на рабочем листе)» — таблица «Технико-экономические показатели» по секциям на рабочем листе **«ТЭП»**
   и файл `ТЭП - <проект>.xlsx` в «Документах». Справа от ТЭП — таблица проверки: по каждой строке и секции какие зоны
   (код, имя, количество, сумма), этажи и квартиры учтены (в Excel — лист «Проверка ТЭП»; лист «Квартиры» — каждая квартира с помещениями).
   В п. 16 1- и 2-комнатные всегда отдельно с кухней и с кухней-столовой, студии — отдельно.
   Застройка, строительный объём, площадь жилого здания — по зонам 8020, 8010, 8030; подвал — зоны подземных этажей
   (индекс этажа < 0), тех. помещения — 4xxx; встроенные — 5xxx (кроме 5020 — кладовые); общедомовые — 2xxx, 6xxx на надземных этажах;
   этажность — надземные этажи с первого до последнего этажа с квартирами; количество этажей = этажность + подземные (отметка этажа ниже −0,5 м, отрицательный индекс или «подвал / подполье / подзем» в названии);
   жители — приведённая площадь / 30 м².
9. «Данные ТЭП и паспортов (файл)…» — `Документы\ТЭП - <проект>.txt`: какие категории в какую строку, округление,
   разделитель в паспортах и значения вручную по секциям (раздел [Вручную], например количество работающих — строка 18).

## Как считается

- Стены — по связям зоны (участки стен вдоль её границы): длина участка × высота отделки − окна и двери этого участка.
- Высота отделки — строго по высоте зоны (пол в ней уже учтён) − толщина потолка. Если полы ещё не замоделированы (нет перекрытия в слое
  «Полы» в зоне), вычитается толщина пола: «Толщина пола» в параметрах зоны, иначе значение по категории из окна. Элементы, которые
  заканчиваются ниже зоны, считаются на ту же высоту, но в таблице проверки получают примечание «ниже зоны, проверить высоту».
- Порядок подкатегорий — как в томе АР: тех.помещения (подвал), встроенные, квартиры, типовой этаж, 1 этаж, общедомовые, чердак.
- Элементы у контура, не взятые по плану (скрытый слой, другой этаж, закрыт элементом скрытого слоя), перечислены на листе «Расчёт» с причиной и координатами.
- Колонны и пилоны зоны — по открытым граням (пилон внутри зоны: две длинные грани + торец).
- По плану добавляются прямые ортогональные и многоугольные стены и колонны этажа зоны (видимые на её плане), которые ограничивают зону,
  но не связаны с ней: считаются грани, обращённые в зону (облицовочная стенка перед стеной закрывает её грань, стыки и щели
  до 5 см между элементами — например, пилон у стены — не считаются).
  Многоугольные стены (например, Г-образная штукатурка вокруг пилона) — по их контуру. Колонна вырезает стену: общая грань
  колонны и стены считается у колонны, а ж/б стены — перед кладкой/ГКЛ (как при пересечении в Archicad): длинная стена КБ,
  перекрытая ж/б участками, делится — ж/б части в монолит, видимая часть КБ в кладку; стена под колонной не считается; стенка перед колонной (облицовка) закрывает её грань.
  О каждом таком элементе — заметка в столбце «Примечание (проверить)» таблицы проверки; на листе «Расчёт» — «по контуру».
- Участки контура зоны без стен и колонн (проходы) выводятся на лист «Расчёт» с длиной.
- Столбец стены — по коду слоя в названии многослойной конструкции: `Ст_В| Ш 15_КБ 190_Ш 15` → слои Ш, КБ, Ш → КБ → столбец 2.
  Есть слой ЖБ — всегда монолит (столбец 1), у однослойной стены — «Ж/Б» в имени строительного материала. ПГП — к керамзитобетону.
  Утеплитель (У, Ут) столбец не определяет. Стенка только из штукатурки (отделка на ж/б стене) — монолит.
- Столбец 3 (межкомнатные перегородки ГКЛ) — только у зон подкатегории «Квартиры», кроме санузлов, ванных, балконов, лоджий, террас;
  у остальных зон такие стены идут в столбец 2 (раздел [Столбец 3] правил; на листе «Расчёт» — «ГКЛ не в квартире»).
- Потолок — чистая площадь зоны. Виды отделки — параметры зоны «Потолок» и «Стены» (номер `00` в начале отбрасывается).
- Подкатегория — по первой цифре кода категории (раздел [Группы] правил): 3 тех.помещения (подвал), 1 квартиры, 2 общедомовые, 5 встроенные,
  4 «1 этаж», 6 «Типовой этаж», 7 «Чердак»; 8 и 9 в ведомость не входят. Если код в категории пустой — берётся первое число из названия категории.
- Строки в «Квартирах» — по видам помещений (раздел [Строки по категориям]: 101x жилые, 102x кухни, 103x/104x/108x прихожие,
  коридоры, гардеробные, 105x санузлы, 106x/107x балконы и лоджии), как в томе АР, даже при одинаковой отделке.
- Остальные строки: внутри подкатегории зоны с одинаковой отделкой потолка и стен — одна строка; в «Наименовании помещений» перечислены
  имена зон (поле «Имя» зоны, «\n» — перенос — заменяется пробелом; пустое имя — из категории) без повторов: «Электрощитовая, лестничная клетка, С/У».
  Если одинаковый перечень с разной отделкой — дописываются этажи: «Лифтовый холл (2-14 эт.)».

## Правила

Файл `Документы\Ведомость отделки - правила.txt` (кнопка «Правила…» в окне открывает его в Блокноте):
заголовок, названия столбцов, коды материалов → столбец, подкатегории по коду категории, замена названий отделки. Удалите файл — вернутся правила по умолчанию. Если файл старее текущей версии правил (строка «# Версия правил: N»),
он заменяется новым, а прежний сохраняется как «Ведомость отделки - правила (старые).txt».

## Сборка

GitHub Actions (`.github/workflows/main.yml`) собирает `VedomostOtdelki.apx` на каждый push — артефакт
**VedomostOtdelki-AC27-Windows**. Установка: «Параметры → Менеджер надстроек → Добавить…».

Проверка логики на Linux:

```
g++ -std=c++17 -ISrc -o /tmp/t tests/test_otd.cpp Src/FinishCore.cpp Src/FinishReport.cpp Src/XlsxWriter.cpp Src/FinishTable.cpp && /tmp/t out.xlsx
g++ -std=c++17 -ISrc -o /tmp/tt tests/test_tep.cpp Src/TepCore.cpp Src/FinishCore.cpp Src/XlsxWriter.cpp Src/FinishTable.cpp && /tmp/tt tep.svg tep.xlsx
```

`Src/FinishCore.*` — правила и расчёт без API, `Src/FinishTable.*` — таблица для рабочего листа,
`Src/FinishReport.*` и `Src/XlsxWriter.*` — Excel,
`Src/TepCore.*` — квартиры, паспорта и ТЭП без API,
`Src/Otdelka.cpp` — окно, чтение модели Archicad, паспорта на плане, ТЭП на рабочем листе.
