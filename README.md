# Ведомость отделки — надстройка для Archicad 27

Считает ведомость отделки помещений по зонам **HimeraZone** (форма как на листе 63 тома АР):
потолки и стены по материалу — монолит ж/б, кладка/керамзитобетон, ГКЛ.

## Как пользоваться

1. «Параметры → Ведомость отделки → Ведомость отделки…».
2. В окне: номер секции (параметр зоны «Секция»), этажи (`1`, `2-14`, `1; 3; 5-7`), толщина пола и потолка.
   Галочка «Брать толщину пола из перекрытия в слое» — если в зоне есть перекрытие в слое «Полы», берётся его толщина.
3. «Рассчитать» — в папке «Документы» появится `Ведомость отделки - секция N - эт. X.xlsx`:
   лист «Ведомость» и проверочный лист «Расчёт» (каждая стена каждой зоны: длина, высота, проёмы, площадь).

## Как считается

- Стены — по связям зоны (участки стен вдоль её границы). Площадь = длина участка × (высота стены − пол − потолок) − окна и двери этого участка (только часть проёма в полосе отделки).
- Столбец стены — по коду слоя в названии многослойной конструкции: `Ст_В| Ш 15_КБ 190_Ш 15` → слои Ш, КБ, Ш → КБ → столбец 2. Стенка только из штукатурки (отделка на ж/б стене) — монолит.
- Колонны и пилоны — по рёбрам контура зоны, лежащим на колонне (столбец монолита).
- Потолок — чистая площадь зоны. Виды отделки — параметры зоны «Потолок» и «Стены» (номер `00` в начале отбрасывается).
- Строки: группа по типу зоны (подвал — отдельная группа), строка по имени зоны. Если у одной строки разная отделка на разных этажах — она делится, этажи дописываются: «Лифтовой холл (2-14 эт.)».

## Правила

Файл `Документы\Ведомость отделки - правила.txt` (кнопка «Правила…» в окне открывает его в Блокноте):
заголовок, названия столбцов, коды материалов → столбец, группы по типу зоны, строки (какие имена зон объединять),
замена названий отделки. Удалите файл — вернутся правила по умолчанию.

## Сборка

GitHub Actions (`.github/workflows/main.yml`) собирает `VedomostOtdelki.apx` на каждый push — артефакт
**VedomostOtdelki-AC27-Windows**. Установка: «Параметры → Менеджер надстроек → Добавить…».

Проверка логики на Linux:

```
g++ -std=c++17 -ISrc -o /tmp/t tests/test_otd.cpp Src/FinishCore.cpp Src/FinishReport.cpp Src/XlsxWriter.cpp && /tmp/t out.xlsx
```

`Src/FinishCore.*` — правила и расчёт без API, `Src/FinishReport.*` и `Src/XlsxWriter.*` — Excel,
`Src/Otdelka.cpp` — окно и чтение модели Archicad.
