# Объект зоны HimeraZone_АСП

`HimeraZone_АСП.xml` — исходник штампа зоны (формат LP_XMLConverter). Сборка: `Собрать HimeraZone_АСП.bat`
(рядом с xml, нужен Archicad 27) → `HimeraZone_АСП.gsm`.

- Основа — HimeraZone22_test (MainGUID 74D2561B-1B23-4787-AE10-4A78AA88340E). Не держите в библиотеке одновременно
  HimeraZone22_test и HimeraZone_АСП — у них один GUID.
- Убран «Особый низ стен» (окно и расчёт): bUseWallDown всегда 0, параметры низа скрыты; поправка длины — на всю высоту.
- Зашиты категории зон 1010…8040 (блок «КОЭФФИЦИЕНТЫ И ИМЕНА ЗОН» мастер-скрипта): список имён зоны, тип помещения
  для ZoneSum (iTypeZone / asAddOn_SubRegul: 1 комнаты, 2 нежилые, 3 летние, 4 общедом., 5 обществ.) и коэффициент
  площади (балкон, терраса, переходной балкон 0,3; лоджия 0,5). Тип помещения у таких зон задаётся категорией и заблокирован.
- Параметры для ZoneSum (asAddOn_*) не менялись. ZoneSum ищет объект по имени «HimeraZone» — имя HimeraZone_АСП
  начинается с него. Надстройка «Ведомость отделки» ищет «HimeraZone» в любой части имени.
- `Категории зон - HimeraZone_АСП.xml` — категории проекта (Менеджер реквизитов) со штампом HimeraZone_АСП:
  импортировать после загрузки объекта в библиотеку.

# Объект паспорта квартиры Паспорт_АСП

`Паспорт_АСП.xml` → `Собрать Паспорт_АСП.bat` → `Паспорт_АСП.gsm`; добавить в библиотеку проекта.
Ставит и обновляет надстройка (меню «Паспорта квартир на планах этажей»). MainGUID 6443E33A-D269-427D-BAE2-7A69743D05AB.
Размеры в мм листа, как у исходных паспортов ZoneSum: ширина колонок wCol1 7,5 и wCol2 9,5, строка hRow2 4,4, текст tSizeA / tSizeT 2,8, шрифт, перья, «Тип жирным»,
«Номер квартиры в паспорте» bAptNum (слева сверху, тип — слева снизу); rPlaceX/rPlaceY — где поставила надстройка (не двигали — переносится при обновлении). Числа — строки stLiving / stArea / stTotal / stReduced (и rLiving… — числами для каталогов),
stKey «секция|квартира» — по нему надстройка находит паспорт при обновлении.
iKind = 1 — встроенное помещение: слева «АП», справа номер помещения (stApt), площадь (stArea, «84,2 м²»), высота (stHeight, «h=3,97м»).

# Категории зон для импорта

`Категории зон - HimeraZone_АСП (импорт).xml` + папка `AddPars` рядом (Менеджер реквизитов требует папку) — собраны из экспорта
проекта (штамп HimeraZone22): у всех категорий штамп HimeraZone_АСП (MainGuid 74D2561B…, в AddPars — тот же UNID), имена без «(1)»,
без дублей (2031 «(копия)», 2050 «МОП_Лифтовый холл», повторы 8/8020/8030/8040), 3070 «Подвал_Подвальное помещение». С версии 4: бывшие 6xxx (эксплуатационные) → 21xx общедомовые,
бывшие 4xxx (ТП_ технические) → 31xx тех.помещения (подвал); новые «1 этаж» (4), 4010 «Индивидуальные кладовые», «Типовой этаж» (6),
6010 «Нежилое помещение». 84 категории.
Списки имён по коду категории — в мастер-скрипте HimeraZone_АСП.
