# Объект зоны HimeraZone_АСП

`HimeraZone_АСП.xml` — исходник штампа зоны (формат LP_XMLConverter). Сборка: `Собрать HimeraZone_АСП.bat`
(рядом с xml, нужен Archicad 27) → `HimeraZone_АСП.gsm`.

- Основа — HimeraZone22_test (MainGUID 74D2561B-1B23-4787-AE10-4A78AA88340E). Не держите в библиотеке одновременно
  HimeraZone22_test и HimeraZone_АСП — у них один GUID.
- Убран «Особый низ стен» (окно и расчёт): bUseWallDown всегда 0, параметры низа скрыты; поправка длины — на всю высоту.
- Зашиты категории зон 1010…8040 (блок «КОЭФФИЦИЕНТЫ И ИМЕНА ЗОН» мастер-скрипта): список имён зоны, тип помещения
  для ZoneSum (iTypeZone / asAddOn_SubRegul: 1 комнаты, 2 нежилые, 3 летние, 4 общедом., 5 обществ.) и коэффициент
  площади (балкон, терраса, переходной балкон 0,3; лоджия 0,5). Тип помещения у таких зон задаётся категорией и заблокирован.
- Параметры для ZoneSum (asAddOn_*) не менялись. ZoneSum ищет объект по имени «HimeraZone» — имя HimeraZone_АСП
  начинается с него. Надстройка «Ведомость отделки» ищет «HimeraZone» в любой части имени.
- `Категории зон - HimeraZone_АСП.xml` — категории проекта (Менеджер реквизитов) со штампом HimeraZone_АСП:
  импортировать после загрузки объекта в библиотеку.
